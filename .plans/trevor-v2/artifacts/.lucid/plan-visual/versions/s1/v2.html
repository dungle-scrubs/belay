Trevor V2 - Host Rebuild on Effect

Rewrite the agent host in TypeScript + Effect v3, compiled to a binary via bun --compile, spawned by the unchanged Rust TUI over JSONL-over-stdio. The host reproduces the wire protocol exactly - the TUI cannot tell it was rewritten.

The 4 kill-gate assumptions all untested · gate Phase 0

A-001gating
Effect v3 (with fiber interruption) runs under bun test AND a bun build --compile binary.
if false: distribution model breaks → fall back to interpreted bun run via TREVOR_HOST_CMD (Hatch 1)
A-003gating
The copied trevorV2/tui compiles (cargo build) against the copied protocol + embedded artifacts.
if false: "reuse unchanged" premise is wrong → reconcile embedded-artifact paths before any host work
A-004gating @ S1
Interrupting an Effect fiber actually tears down the underlying pi-ai stream (no post-cancel assistant.delta).
if false: port race-and-abandon + per-runId delta suppression; accept upstreamStopCertainty=local_abort_only (Hatch 2)
A-002non-gating
Effect v3 is viable for the project horizon; v3→v4 upgrade cost is acceptable.
if false: re-evaluate entry version; non-gating
